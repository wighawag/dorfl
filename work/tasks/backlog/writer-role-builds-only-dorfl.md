## What to build

The writer-role setup action `.github/actions/dorfl-setup-writer` (generated by `generateWriterSetupAction` in `install-ci-core.ts`) runs, in workspace install mode, `pnpm install --frozen-lockfile --ignore-scripts` and `pnpm -r build` over the exported base tree. `pnpm -r build` builds every workspace package, the website included, inside the lock and apply jobs that hold the write token. Decision 8 of ADR `ci-agent-job-holds-no-write-token` accepts building dorfl from the base sha in the write jobs; it does not need the other packages, and building them runs more repository code next to the write token than necessary (and costs time on every item). Flagged at Gate-3 of `ci-split-generate-workflows` (PR #424).

Build only dorfl and what it depends on (for example `pnpm --filter dorfl... build`, and a matching filtered install if that is sound with a frozen lockfile), in the generator and in this repository's regenerated action.

`humanOnly` because it edits `.github/` (CI refuses to land it). Build it locally.
