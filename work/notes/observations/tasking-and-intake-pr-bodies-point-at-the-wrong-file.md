Found in the CI sandbox `wighawag/dorfl-ci-sandbox` (private, dorfl `main@e972795d` installed from a tarball, workflows generated by `install-ci`), while exercising the split CI workflows end to end.

Tasking PR #10 starts with `Task: work/tasks/done/text-layout-module-wrap-pad-and-align.md`, a path that never exists: `composeProposeBody` (`integration-core.ts`) always writes a task's done path, and the tasking land reuses it for a spec (the real file is `work/specs/tasked/<slug>.md`). Intake PR #6 has an empty body (no pointer to the staged task or the issue). Build PRs (#11) are correct.
