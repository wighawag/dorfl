The CI split where the agent job holds no write token now covers the tree-less rungs: `advance <item> --phase lock|agent|apply` on an item that classifies on the `surface`, `triage-observation` or `apply` rung runs that rung in three jobs (the build and tasking paths are routed as before; the agent and apply phases follow the lock job's `rung` output). The lock phase classifies the item at the arbiter's `main`, takes the advancing lock and publishes `needsAgent: false` when the rung launches no agent: the triage back-fill of the `triaged:` marker and an already-triaged note, the surface short-circuit for an observation with nothing to ask, an answered `kind: stuck` entry, and a task or spec content answer. An answered `kind: merge` entry is refused before any write (it is not split yet). The agent phase runs the rung body on the lock job's base with the real surface, triage and apply-decision agents and every write stubbed out, writes nothing to the arbiter, and hands over `surface`, `triage` (the triage gate's disposition, or `keep` plus the surface questions) or `apply-decision` (the agentic verdict). The apply phase reads the handoff as hostile (another item, an unsafe slug or item reference, an outcome or disposition outside its enum, an auto-disposition when `observationTriage` is not `auto`, or another rung's intent is rejected and the item is surfaced), then runs the same rung body on a fresh checkout of the arbiter's `main` with the agents replaced by replays of the checked handoff, so it produces the same commits as the single-process `advance`. Before the tree-less publish it checks the checkout carries exactly the rung's own commit on top of the fetched `main`, and refuses the publish otherwise; it then releases the lock, leased on the lock job's lock. A failed or timed-out agent job surfaces the item; a real cancel only releases the lock. Surface questions travel as their question text only (their optional context and default are not carried in the phase split). No generated workflow uses `--phase` yet, and nothing changes without it.
